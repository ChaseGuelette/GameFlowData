# Development Session 68 -- 2026-03-06

## Summary

Added "Take Bet" functionality to the AnalysisModal and improved the History page with matchup info and per-stat win rate breakdown.

## What Was Built

### AnalysisModal "Take Bet" Button

Users can now place a bet directly from the AnalysisModal with full control over which sportsbook line and stake to use.

**Flow:**
1. User opens AnalysisModal, selects a sportsbook line
2. Footer shows stake input (pre-filled from Kelly recommendation) + "Take Bet" button
3. User optionally edits stake, clicks "Take Bet"
4. Bet recorded to `user_bets` with exact book/odds/line/stake
5. Button shows "Bet Taken!", PropCard checkmark turns green
6. Modal auto-closes after brief delay

**Technical details:**
- `onTakeBet` optional prop on AnalysisModal with `TakeBetData` type
- `customStake` string state synced from `sizingData.recommendedBet` via `useEffect`
- `betPlaced` boolean disables button and input after placement
- Sizing IIFE lifted to `useMemo` (`sizingData`) for reuse in footer
- `betPlaced` resets when `prediction.id` changes

### `placeBetCustom()` Standalone Function

New exported async function in `useUserBets.ts` that places a bet with caller-provided parameters. Separate from the hook's `toggleBet` to allow use from AnalysisModal without needing the hook's date-scoped state.

```typescript
export async function placeBetCustom(params: PlaceBetCustomParams): Promise<{ id: number } | null>
```

### `markBetTaken()` Hook Method

New method on `useUserBets` return that adds a bet to the local `takenBets` set + `betRowsRef` after `placeBetCustom` succeeds. This syncs the PropCard checkmark without a full refetch.

### Team/Opponent in user_bets

**Migration 013:** Added `team_abbrev` and `opponent_abbrev` nullable text columns to `user_bets` table. No backfill — old bets display without matchup info.

Both `toggleBet` (PropCard path) and `placeBetCustom` (AnalysisModal path) now include these columns in the upsert.

### BetCard Matchup Display

BetCards now show matchup info below the player name:
- `"LAL vs SAS • 2026-03-06"` when team/opponent available
- `"2026-03-06"` fallback for older bets

### Per-Stat Win Rate Cards

HistorySummary now shows up to 3 cards below the main summary grid — one per stat type (PTS/REB/AST) that has resolved bet data. Each card displays the stat badge, win rate %, and W-L record.
