# Development Session 50 — 2026-02-26

## Summary

Implemented MLB Statcast and FanGraphs advanced stats scrapers — Phase 2 of the MLB data pipeline. These provide quality-of-contact metrics and season-level advanced statistics critical for MLB player prop modeling.

## Problem

Phase 1 MLB scrapers (boxscores, props, game lines, reference data) were complete, but boxscore stats alone are insufficient for MLB modeling. Unlike NBA where advanced stats come from the same API, MLB modeling requires:
- **Statcast data** — exit velocity, barrel%, xBA, xwOBA (quality of contact)
- **FanGraphs stats** — wRC+, FIP, SIERA (season-level advanced metrics)

These are available via the `pybaseball` library (free, no auth).

## What Was Built

### 1. Supabase Migration — 3 New Tables

- **`mlb_player_game_statcast_batting`** — Per-game batting aggregates (25+ columns). PK: `(player_id, game_date)`. Contact quality, expected stats, batted ball types, spray direction, plate discipline.
- **`mlb_player_game_statcast_pitching`** — Per-game pitching aggregates (28+ columns). PK: `(player_id, game_date)`. Contact quality against, velocity/spin, pitch mix, CSW%.
- **`mlb_player_season_advanced`** — Season-level FanGraphs stats. PK: `(player_id, season, player_type)`. Batter: wRC+, wOBA, ISO, WAR. Pitcher: FIP, xFIP, xERA, SIERA.

### 2. `mlb_statcast_scraper.py`

Daily Statcast scraper using `pybaseball.statcast(start_dt, end_dt)`:
- Fetches all pitches for a single day (~4,500 rows)
- Aggregates per `(batter, game_date)` and `(pitcher, game_date)`
- Key batting aggregations: avg/max exit velocity, barrel%, hard hit%, sweet spot%, xBA, xSLG, xwOBA, GB/FB/LD/popup%, pull/center/oppo%, zone%, chase%, whiff%
- Key pitching aggregations: contact quality against, avg/max fastball velo, avg spin rates, pitch mix (fastball/breaking/offspeed %), batted ball distribution, zone%, chase%, whiff%, CSW%
- Pitch type classification: FF/SI/FC → fastball, SL/CU/KC/SV → breaking, CH/FS → offspeed
- `ON CONFLICT DO UPDATE` upserts (Statcast data corrected retroactively)
- CLI: `--date`, `--yesterday`, `--backfill --start-date --end-date`

### 3. `mlb_fangraphs_scraper.py`

Season-level FanGraphs stats via `pybaseball.batting_stats()` / `pitching_stats()`:
- Player ID resolution: name match against `mlb_players` → fallback to `playerid_reverse_lookup()` crosswalk
- Handles name variations (Jr., Sr., II, III)
- Auto-inserts unknown players via `_ensure_player()` (fixed FK violation during testing)
- CLI: `--season 2025`, `--all-seasons`, `--batting-only`, `--pitching-only`

### 4. `mlb_statcast_backfill.py`

Bulk Statcast backfill orchestrator:
- Day-by-day iteration through MLB seasons (March–October)
- Progress file (`mlb_statcast_backfill_progress.json`) for resume
- 1 req/sec rate limiting, tqdm progress bar
- CLI: `--seasons 2024 2025`, `--start-date/--end-date`, `--no-resume`
