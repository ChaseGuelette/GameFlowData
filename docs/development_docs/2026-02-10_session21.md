## C5 THREES Multiclass Model

### Why Multiclass?

Previous approaches (C3 hurdle + quantile regression, C4 truncated negative binomial) failed because:
- Quantile regression produces continuous values for discrete outcomes (can't have 2.3 threes)
- Interpolation between quantile points is too coarse for a distribution with only ~8 values
- Count distribution conversion added complexity without solving the core issue

**Multiclass directly solves these problems:**
- Discrete outcomes (0, 1, 2, ... made threes) are naturally categorical
- XGBoost `multi:softprob` directly outputs calibrated class probabilities
- No quantile-to-PMF conversion needed — model outputs ARE the distribution
- Categorical sampling produces integer counts directly

### Architecture

```
ThreesMulticlassModel
├── XGBClassifier (objective='multi:softprob', num_class=9)
├── Classes 0-7: Exact counts (0, 1, 2, 3, 4, 5, 6, 7 made threes)
├── Class 8: "8 or more" (capped/binned)
└── Training target: threes_per_game binned to 0-8 (not threes_per_min rate)
```

### Key Implementation Details

**Training:**
```python
# Bin threes_per_game to 0-8 classes
y_binned = np.clip(y_threes.astype(int), 0, 8)

# Train XGBoost multiclass
model = XGBClassifier(
    objective='multi:softprob',
    num_class=9,
    n_estimators=config.n_estimators,
    ...
)
model.fit(X, y_binned)
```

**Sampling:**
```python
def _sample_threes_multiclass(pmf: np.ndarray, n_samples: int):
    """Sample from PMF using weighted random choice."""
    return np.random.choice(range(9), size=n_samples, p=pmf)
```

### Bug Fixes

1. **`best_iteration` AttributeError:** XGBoost only sets `best_iteration` when early stopping triggers. Added try/except fallback to `n_estimators`.
