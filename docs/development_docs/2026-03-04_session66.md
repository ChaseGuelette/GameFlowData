# Development Session 66 — 2026-03-04

## Summary

Multi-Select Sportsbook Filter + Pending Bets in History. Replaced the single-select sportsbook dropdown with a multi-select checkbox dropdown where all books start checked and unchecking excludes. Added pending bet visibility to the History page so users can see outstanding bets awaiting resolution. Also created a portable scraper zip for running the NBA unified scraper on a separate machine.

## Problem

The dashboard's sportsbook filter was a single-select dropdown — either "All Books" or one specific book. Users couldn't filter to a subset of books (e.g., "show me picks available on DraftKings OR FanDuel but not BetMGM"). Additionally, pending/outstanding bets were invisible — they were recorded in `user_bets` but hidden from History and Performance views until resolved the next morning.

## What Was Built

### Multi-Select Sportsbook Filter

**`BookFilterDropdown.tsx`** — New component:
- Dropdown button + floating checkbox panel
- Button label: "All Books" when all checked, "Books (N)" when some unchecked
- One checkbox per sportsbook, filtered by user's state via `STATE_SPORTSBOOKS`
- "Select All" / "Clear All" toggle at the top
- Closes on outside click (mousedown listener) or Escape key
- Props: `excludedBooks: Set<string>`, `onChange`, `userState`

**Dashboard page state changes:**
- Replaced `bookFilter: string` (single book key) with `excludedBooks: Set<string>` (empty = all included)
- Availability query: when `excludedBooks` is non-empty, computes `activeBooks = allowedBooks - excluded`, then queries `raw_player_props_combined` with `.in('bookmaker', activeBooks)`. When empty, skips query entirely (same perf as old "All Books").
- State-change cleanup: when user changes state, removes any excluded books that aren't legal in the new state

### Pending Bets in History

**HistoryFilters** — Added "Pending" to the status filter tabs (All / Pending / Won / Lost / Push).

**History page** — My Bets "All" filter now includes pending bets (previously filtered them out). Only "cancelled" is excluded from the default view.

**HistorySummary** — Conditionally shows "Pending" count (blue text) in the summary stats bar when outstanding bets exist. Win rate and P&L are still computed from resolved bets only (pending excluded from calculations).

**BetCard** — Already handled pending status (shows "Awaiting result" instead of actual value), no changes needed.

## Design Decisions

| Decision | Choice | Why |
|----------|--------|-----|
| State shape | `excludedBooks: Set<string>` (exclusion set) | Empty set = no filtering, natural default. Adding a book to exclusion set is more intuitive than managing an inclusion set |
| Availability query | `.in('bookmaker', activeBooks)` | Shows predictions available at ANY of the active books, same semantic as old single-book filter but for multiple |
| Pending in History | Show in "All", add "Pending" filter tab | Users need to see outstanding bets; separate tab allows focused view |
| Summary stats | Pending count shown, excluded from W/L/P&L | Pending bets don't have outcomes yet; including them would skew metrics |
