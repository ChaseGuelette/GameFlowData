# Session 22 — Archive THREES Model

**Date:** 2026-02-10

## Summary

This session archived the THREES (3-pointer) model after extensive development across C3 (hurdle), C4 (truncated NegBin), and C5 (multiclass PMF) approaches. The decision was driven by poor market coverage and insufficient betting volume.

## Why Archived?

### Market Reality

| Metric | Value | Impact |
|--------|-------|--------|
| Line coverage | ~50% | Half of predictions had no odds available |
| Backtest bets | 2 of 78 | Only 2.6% of bets came from THREES |
| Development time | 4+ sessions | Significant effort for minimal return |

### Root Cause

Sportsbooks don't consistently offer 3-pointer props for all players. Unlike PTS/REB/AST which have near-universal coverage, THREES props are typically only available for:
- High-volume shooters (top 3PT attempt leaders)
- Popular players on nationally televised games
- High-profile matchups

This is a **market reality issue**, not a code or model issue.
