## Technical Details

### Under Probability Estimation

The `estimateUnderProb()` function correctly calculates Under probability:

```typescript
// 5 quantile points: (value, P(Under))
const points = [
  { val: q10, prob: 0.90 },  // Easy Under (floor outcome)
  { val: q25, prob: 0.75 },
  { val: q50, prob: 0.50 },  // Median
  { val: q75, prob: 0.25 },
  { val: q90, prob: 0.10 },  // Hard Under (ceiling outcome)
]

// For lines above q90, extrapolate (higher line = easier Under)
if (line >= q90) {
  const slope = (points[4].prob - points[3].prob) / (points[4].val - points[3].val)
  const extrapolated = points[4].prob + slope * (line - points[4].val)
  return Math.max(0.90, Math.min(0.99, extrapolated))
}
```

### Kelly Formula

```typescript
const calculateKelly = (modelProb: number, odds: number, kellyFraction: number): number => {
  if (odds === 0 || modelProb <= 0 || modelProb >= 1) return 0
  const b = odds > 0 ? odds / 100 : 100 / Math.abs(odds)  // decimal odds - 1
  const f = (modelProb * (b + 1) - 1) / b  // full Kelly fraction
  if (f <= 0) return 0
  return Math.min(f * kellyFraction, 0.25)  // cap at 25% of bankroll
}
```

### LocalStorage Lazy Initialization

Fixed useState + useEffect lint warning:

```typescript
// Before (lint error)
const [bankroll, setBankroll] = useState(1000)
useEffect(() => {
  const saved = localStorage.getItem('gameflow_bankroll')
  if (saved) setBankroll(parseFloat(saved))
}, [])

// After (lazy initialization)
const [bankroll, setBankroll] = useState<number>(() => {
  if (typeof window !== 'undefined') {
    const saved = localStorage.getItem('gameflow_bankroll')
    return saved ? parseFloat(saved) : 1000
  }
  return 1000
})
```
