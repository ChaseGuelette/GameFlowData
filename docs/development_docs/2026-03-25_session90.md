## What Was Done

### 1. Diagnosed Missing MLB Predictions

MLB inference job was running on Railway (confirmed in logs at 18:30 UTC) and producing 480 batter predictions, but all had `line = NULL` and `edge = NULL`. Root cause: no MLB lines scraping job existed. The scrapers (`mlb_daily_player_props_scraper.py`, `mlb_daily_game_lines_scraper.py`) were built but had no orchestration wrapper or scheduler entry.

### 2. Built `mlb_lines_job.py`

**File:** `src/orchestration/mlb_lines_job.py` (new)

Mirrors NBA `lines_job.py` pattern:
- `--live` — Uses live Odds API endpoints
- `--props-only` — Props + linker only (skip game lines)
- `--parallel` — Game lines and props run concurrently via threads
- `--extended` — Include extended prop markets
- `--skip-linker` — Skip incremental linker step

Pipeline: MLB game lines scraper → MLB props scraper → MLB incremental linker

### 3. Added MLB Lines to Scheduler

4 new cron entries in `scheduler.py`:
- 12:00 PM ET — Full lines scrape (`--live --parallel`)
- 1:00 PM ET — Props-only refresh (`--live --props-only`, silent on success)
- 5:00 PM ET — Full lines scrape (catch evening props)
- 6:00 PM ET — Props-only refresh before evening inference

Lines run before existing inference jobs (1:30 PM, 6:30 PM) to ensure edges are calculated.

### 4. Fixed Pitcher K Inference

**File:** `src/models/mlb/mlb_daily_runner.py`

`MLBFeatureStore.get_player_game_features()` expects `game_date`, `opp_team_id`, `venue_id`, `season` but the daily runner was passing `as_of_date`, `opponent_id` and missing `venue_id`/`season`. Fixed:
- `as_of_date=target_date` → `game_date=str(target_date)`
- `opponent_id=` → `opp_team_id=`
- Added `venue_id=pitcher.get("venue_id") or 0`
- Added `season=pitcher.get("season") or target_date.year`
- Added `venue_id` and `season` to pitcher dict construction (both home and away)

### 5. First MLB Predictions Generated

Ran full pipeline locally:
1. Props scraper: 18,202 rows across ~15 games (372 API credits)
2. Game lines scraper: 1,766 rows (9 credits)
3. Linker: 18,202 game matches, 18,045 player matches
4. Inference: 481 predictions (480 batter + 1 pitcher K)
5. Edge calculation: 974 prop lines matched, 45 under edges >5%, 19 BL-recommended
6. Paper bets: 16 bets placed
