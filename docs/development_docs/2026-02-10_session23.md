# Session 23 — Per-Stat Configuration System

**Date:** 2026-02-10

## Summary

This session implemented a per-stat configuration system enabling different edge thresholds and Black-Litterman tau values for each stat type (pts, reb, ast). The implementation is motivated by backtesting results showing significant performance differences between stats.

## Motivation

| Stat | ROI | Observation |
|------|-----|-------------|
| REB | +7.9% | Strongest performer |
| AST | +3.2% | Marginal profitability |
| PTS | Variable | Depends on configuration |

**Key insight:** A single global edge threshold treats all stats equally, but they have different profitability profiles. Per-stat configuration allows:
- Looser thresholds on strong stats (REB) to capture more bets
- Tighter thresholds on weak stats (AST) to filter aggressively
- Different BL tau values for stat-specific calibration
- Complete BL disable for stats that don't benefit

### Core Classes

```python
@dataclass
class StatConfig:
    """Configuration for a single stat type."""
    stat: str
    enabled: bool = True
    edge_threshold: float | None = None  # None = use global
    bl_tau: float | None = None          # None = no BL

@dataclass
class StatConfigSet:
    """Container with global fallbacks."""
    global_edge_threshold: float = 0.05
    global_bl_tau: float | None = None
    configs: dict[str, StatConfig] = field(default_factory=dict)

    def get_edge_threshold(self, stat: str) -> float
    def get_bl_tau(self, stat: str) -> float | None
    def is_stat_enabled(self, stat: str) -> bool

    @classmethod
    def from_cli_args(cls, edge_values, tau_values, stats) -> StatConfigSet
```

### CLI Format

```bash
# Backward compatible (global)

# Mixed (global default + overrides)
```

## Technical Details

### Parsing Logic

The `parse_stat_param()` helper handles three formats:

1. **Global only:** `["0.05"]` → `(0.05, {})`
2. **Per-stat only:** `["pts=0.10", "reb=0.07"]` → `(None, {"pts": 0.10, "reb": 0.07})`
3. **Mixed:** `["0.05", "pts=0.10"]` → `(0.05, {"pts": 0.10})`

Special values:
- `"none"` → Python `None` (disables BL for that stat)
- Stat names are case-insensitive: `"PTS=0.10"` → `{"pts": 0.10}`

### Precedence

1. Per-stat value (if configured)
2. Global value (if set)
3. Default value (0.05 for edge threshold)

### Type Narrowing Fix

Pyright had trouble with the original `get_edge_threshold()`:

```python
# Original (failed type narrowing)
def get_edge_threshold(self, stat: str) -> float:
    if stat in self.configs and self.configs[stat].edge_threshold is not None:
        return self.configs[stat].edge_threshold  # Type error!
    return self.global_edge_threshold
```

Fixed by using a local variable:

```python
def get_edge_threshold(self, stat: str) -> float:
    if stat in self.configs:
        threshold = self.configs[stat].edge_threshold
        if threshold is not None:
            return threshold
    return self.global_edge_threshold
```

## Future Considerations

### Sweep Grid Strategy

With per-stat parameters, the sweep space could explode:
- 3 stats × N edge values × M tau values = large grid

Recommended approach for future sweeps:
```bash
# Sweep one stat at a time, hold others constant
python run_sweep.py \
    --edge pts=0.05,0.07,0.10 reb=0.07 ast=0.15

# Or sweep globally first, then per-stat fine-tuning
```

### Per-Stat Kelly Fractions

Explicitly **excluded** from this implementation by user request. Kelly fraction remains global. Could be added later if needed, following the same pattern.
