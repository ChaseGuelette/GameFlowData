# Development Session 37 — 2026-02-18

## Summary

Built the social media pick image generator (`src/social/`) — a Python CLI tool that auto-generates branded dark-themed images from daily predictions for Instagram, TikTok, and Discord marketing. Three card types: daily slate, individual pick, and results recap.

## Context

GameFlowData needs organic community growth before monetizing with paid subscriptions. The strategy: post professional daily pick images and results recaps to social media, funnel followers to Discord, then convert to paid subscribers once trust is established. Manual graphic creation is unsustainable — this tool automates the entire process.

## Changes Made

### 1. New Package: `src/social/`

**`theme.py`** (~210 lines) — Constants and drawing helpers:
- Color palette matching dashboard Tailwind dark theme (slate-950/800/700 backgrounds, green/yellow/slate edge tiers)
- Font loading with `@lru_cache` for Montserrat Bold/SemiBold/Medium
- Edge tier logic mirroring `dashboard/src/lib/utils.ts:getEdgeTier()`
- Star rating formula matching `PropCard.tsx:31`: `min(5, max(1, ceil(abs(edge) * 50)))`
- Drawing helpers: `draw_rounded_rect()`, `draw_circle_image()`, `draw_text_centered()`, `draw_star_rating()`, `draw_stat_badge()`
- Placeholder headshot silhouette generator matching dashboard SVG

**`data_provider.py`** (~155 lines) — Sync DB queries:
- `get_top_picks_sync()` — Top N picks from `daily_predictions` by best edge
- `get_resolved_bets()` — Resolved paper bets for a date
- `get_daily_summary()` — Daily log from `paper_trading_daily_log`
- `get_performance_stats_sync()` — Season aggregate from `paper_bets`
- Uses `src/db/client.get_engine()` directly — intentionally NOT reusing async Discord services

**`card_renderer.py`** (~360 lines) — Three renderer classes:
- `HeadshotCache` — Downloads from NBA CDN, caches to `data/headshots/`, saves 1px marker on failure to prevent retry storms
- `PickCardRenderer` — Individual player feature card with headshot glow ring, star rating, confidence label, projection range
- `SlateCardRenderer` — Multi-pick daily card with rows of headshots, names, stat badges, directions, star ratings
- `ResultsCardRenderer` — Yesterday's outcomes with green/red status icons, P&L, season stats footer
- All renderers support square (1080x1080) and story (1080x1920) formats

**`generate_images.py`** (~190 lines) — CLI entry point:
- argparse with --date, --type (picks/results/both), --format, --top, --min-edge, --output-dir, --individual, --dry-run
- Lazy imports so --dry-run works without DB connection
- Date logic: `--type both` fetches picks from --date, results from --date minus 1
