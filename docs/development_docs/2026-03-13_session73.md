## Key Design Decisions

- **Two separate bankroll values** — `initialBankroll` (what you started with) vs `bankroll` (current). Initial is for ROI/growth calculations in charts. Current is for Kelly bet sizing and Navbar display. This separates "how am I doing?" from "how should I size my next bet?".
- **Date range shared across tabs** — Both My Bets and Model History tabs use the same `startDate`/`endDate`. Changing the date range re-fetches both datasets. Simpler UX than independent date ranges per tab.
- **Presets as convenience, not constraint** — The 7D/30D/90D/All buttons set both dates simultaneously. Users can still manually pick any arbitrary range via the date inputs.
- **Navbar shows user bankroll, not paper sim** — The paper trading daily log balance is a simulation. The user's actual bankroll (set on Account page) is more relevant for Navbar display and bet sizing.
