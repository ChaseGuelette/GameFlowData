# Development Session 74 -- 2026-03-17

## Summary

Added a minimum-minutes filter to the rolling average pipeline to prevent injury-exit games (< 5 minutes) from corrupting player stat features. Fixed a persistent PgBouncer/Supabase connection pooler timeout that prevented all write operations (TRUNCATE and large UPSERTs) from completing.

## What Was Built

### 1. Minimum-Minutes Filter for Rolling Averages

**Files:** `src/processing/populate_average_stats.py`, `src/processing/populate_average_stats_incremental.py`

Added `MIN_MINUTES_FOR_STATS = 5` constant. Before computing rolling averages, a boolean mask is applied to filter out games where the player played fewer than 5 minutes:

```python
min_mask = player_df["min"].shift(1) >= MIN_MINUTES_FOR_STATS
shifted = player_df[stat].shift(1).where(min_mask)
```

This is applied to:
- All rolling stat averages (L5, L15, SZN) — 20 stats
- L3 rolling averages (B3 features) — 5 stats
- L5 standard deviations (B3/B4 features) — 5 stats
- `min_floor_l5` (B4 feature)
- `games_started_l5` (B4 feature)

Schedule features (`rest_days`, `games_last_7d`) and game counts (`games_l5`, `games_l15`, `games_szn`) are intentionally NOT filtered — they track schedule density, not stat performance.

### 2. PgBouncer Write Fix

**File:** `src/processing/populate_average_stats.py`

The full backfill pipeline was failing on all write operations with `SSL SYSCALL error: EOF detected` after ~4.5 minutes. The root cause was the Supabase connection pooler (PgBouncer on port 6543) dropping idle connections.

Three changes fixed this:
1. **`TRUNCATE` → `DELETE FROM`** — TRUNCATE requires an AccessExclusive lock which PgBouncer struggles with on large tables (434K rows). DELETE works transactionally through the pooler.
2. **`engine.dispose()`** before write phase — clears stale pooled connections that went idle during the ~10-second computation phase.
3. **Fresh connection per batch** — each batch INSERT gets its own `engine.begin()` context instead of sharing one long-lived connection for all 230 batches.

### 3. Unit Tests

**File:** `tests/test_populate_average_stats.py`

Added 3 tests:
- `test_low_minutes_games_excluded_from_rolling` — 7-game player with 1-min game at index 3. Verifies avg_reb_l5 = 8.5 (not 6.8), min_floor_l5 = 28.0 (not 1.0), rest_days still counts the 1-min game.
- `test_all_low_minutes_produces_nan` — 4-game player where first 3 games < 5 min. Verifies avg_reb_l5 is NaN for the last row.
- `test_low_minutes_excluded_incremental` — Same scenario run through the incremental pipeline's `calculate_basic_rolling_for_player()`.

## Motivation

Leonard Miller's REB prediction for 3/16 exposed the structural weakness. His game log:
- 3/13: 36 min, 8 reb
- 3/12: 31 min, 9 reb
- 3/10: 38 min, 11 reb
- 3/08: **1 min, 0 reb** (injury exit)
- 3/05: 24 min, 9 reb

Without filter: `avg_reb_l5 = (8+9+11+0+9)/5 = 7.40`, `min_floor_l5 = 1.00`
With filter: `avg_reb_l5 = (8+9+11+9)/4 = 9.25`, `min_floor_l5 = 24.00`

The unfiltered 7.40 produced a 35-point probability disagreement with the market, which had him at 7.5. The filtered 9.25 aligns much better with his actual production level.
