# Development Session 80 -- 2026-03-21

## Summary

Added threes, steals, and blocks support to the DFS Edge Finder page. Extended `StatType` to 6 stats, added market mappings for 3 new markets, made DFS stat filter dynamic, and removed the `market_key` filter from the `get_sportsbook_lines_by_games` RPC so it returns all sportsbook markets. Previously 18.5% of daily DFS lines (232 lines) were invisible because they had no market mapping.

## What Was Done

### 1. Extended StatType and Constants

**File:** `dashboard/src/types/predictions.ts`

- Added `'stl' | 'blk' | '3pm'` to `StatType` union (was `'pts' | 'reb' | 'ast'`)
- Added labels: `stl: 'Steals'`, `blk: 'Blocks'`, `'3pm': 'Threes'`
- Added badge colors: `stl: 'bg-orange-500'`, `blk: 'bg-red-500'`, `'3pm': 'bg-cyan-500'`

### 2. Extended DFS Market Mappings

**File:** `dashboard/src/types/dfs.ts`

- Added `MARKET_TO_STAT` entries: `player_steals → stl`, `player_blocks → blk`, `player_threes → 3pm`
- Added `STAT_TO_MARKET` reverse entries
- Changed `STAT_TO_MARKET` type from `Record<StatType, string>` to `Record<string, string>` for compatibility with the expanded union

### 3. Dynamic DFS Stat Filter

**File:** `dashboard/src/components/dfs/DfsFilters.tsx`

Changed from hardcoded 3-stat list:
```typescript
// Before
{ value: 'pts', label: STAT_LABELS.pts },
{ value: 'reb', label: STAT_LABELS.reb },
{ value: 'ast', label: STAT_LABELS.ast },

// After
...Object.entries(STAT_LABELS).map(([k, v]) => ({ value: k as StatType, label: v })),
```

DFS stat filter now shows all 6 buttons: All / Points / Rebounds / Assists / Steals / Blocks / Threes.

### 4. AnalysisModal Type Compatibility

**File:** `dashboard/src/components/analysis/AnalysisModal.tsx`

- Relaxed `STAT_COLUMN_MAP` from `Record<StatType, keyof PlayerGameStats>` to `Record<string, keyof PlayerGameStats>`
- Relaxed local `STAT_TO_MARKET` from `Record<StatType, string>` to `Record<string, string>`
- Added `stl/blk/3pm` entries to local `STAT_TO_MARKET`

Both changes prevent TypeScript errors since `Record<StatType, ...>` now requires 6 keys but these maps only need 3 for the AnalysisModal's use case.

### 5. RPC Market Filter Removed (Migration 020)

**File:** `database/migrations/020_add_sportsbook_markets.sql`

Replaced `get_sportsbook_lines_by_games` RPC to remove the hardcoded `market_key IN ('player_points', 'player_rebounds', 'player_assists')` filter. The RPC now returns all sportsbook markets. The frontend already filters via `MARKET_TO_STAT` so only mapped markets are used.

### What Was NOT Changed

- **`FilterTabs.tsx`** — Prediction pages (picks, performance, history) remain hardcoded to PTS/REB/AST. The model only predicts 3 stats; the DFS page shows all 6 for market edge comparison only.
- **`get_dfs_lines` RPC** — Already returns all markets (no filter). No change needed.
- **`get_sportsbook_lines` RPC** — Date-based version unchanged. Only the game_id-based version (`get_sportsbook_lines_by_games`) was modified.
