## What Was Built

### 1. Scoreboard API Route

**File:** `dashboard/src/app/api/scoreboard/route.ts`

New server-side API route that proxies the NBA CDN live scoreboard:
- Fetches `cdn.nba.com/static/json/liveData/scoreboard/todaysScoreboard_00.json`
- Uses same CDN headers as existing `/api/games` route (User-Agent, Referer, Origin)
- Returns `Record<gameId, GameStatusInfo>` map with per-game status
- 30-second ISR cache (`next: { revalidate: 30 }`)
- Returns `{}` on any error (client falls back to time-based)

### 2. useGameStatus Polling Hook

**File:** `dashboard/src/lib/hooks/useGameStatus.ts`

Client-side React hook following existing `useUserBets`/`useUserPreferences` patterns:
- `useGameStatus(isToday: boolean): GameStatusMap`
- Polls `/api/scoreboard` every 30s when `isToday=true`
- Returns empty `Map<string, GameStatusInfo>` when not today (no polling)
- Cleans up interval on unmount or when switching away from today
- Preserves previous state on fetch errors (no flickering)

## Key Design Decisions

- **30s polling matches ISR cache** — Client polls every 30s, API route caches for 30s. No wasted upstream CDN requests since ISR serves cached responses within the revalidation window.
- **Optional `gameStatusMap` on all components** — Components still work without it (fall back to time-based). This means historical date views work unchanged.
- **NBA CDN game_id matches our game_id** — Both use zero-padded 10-digit format (e.g., `0022500947`). No ID translation needed.
- **`gameStatusText` displayed in badges** — Users see "Q3 5:42" or "Halftime" instead of just "Live", and "Final" instead of a 3-hour timer guess.
- **Existing `isGameLive()`/`isGameDone()` preserved** — They serve as the fallback layer. No breaking changes for any code that uses them directly.
- **Error resilience** — API route returns `{}` on any error. Hook preserves previous state on fetch failure. Components fall through to time-based. Multiple layers of graceful degradation.
