### 1. BL Sizing Parameter Implementation

**Problem:** The BL confidence function crushes edge probabilities toward the market prior, making edge-based betting impossible with BL enabled. However, BL-blended probabilities could still be useful for position sizing (Kelly stake calculation) even when using raw model probabilities for edge detection.

**Solution:** Added `--bl-sizing-tau` parameter to enable BL blending specifically for Kelly sizing without affecting edge calculation.

**Implementation:**
- Added `--bl-sizing-tau` CLI parameter to `run_backtest.py`
- Added `bl_sizing_blender` field to `BacktestHarness`
- Modified `_calculate_edges()` to compute `sizing_prob_over`/`sizing_prob_under` columns
- Modified `BetSimulator.place_bet()` to accept optional `sizing_prob` parameter

**Verification:**
- One-day backtest confirmed same bet count with different stake sizes
- BL sizing produces smaller stakes (as expected, since it blends toward market)

### 2. Model Performance Analysis

**Key Finding:** Model is no longer catastrophically overconfident:
- Brier score improved: 0.2705 → 0.2506
- No-BL approach shows +3.5% ROI
- REB stat continues to be the strongest performer

**BL Confidence Issue Persists:**
The structural problem with the BL confidence function remains. For realistic betting edges (z < 0.5), the exponential confidence formula `1 - exp(-0.5 * z²)` produces near-zero values, crushing all edges below practical thresholds.

## Design Decisions

1. **Separate sizing blender:** Rather than modifying the existing BL blending logic, added a separate blender instance for sizing. This keeps edge detection and position sizing independent, allowing experimentation with different tau values for each.

2. **Optional sizing_prob parameter:** The `place_bet()` method defaults to model probability when `sizing_prob` is not provided, maintaining backward compatibility.

3. **Combo markets not yet modeled:** The new combo markets (PRA, P+R, etc.) are stored but not yet used for predictions. They can be derived from existing MC samples (sum of individual stat predictions) without requiring additional models.
