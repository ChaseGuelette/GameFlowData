# Development Session 36 — 2026-02-18

## Summary

Implemented the per-stat calibration diagnostic tool (C2) — a standalone CLI script that produces a per-stat (PTS/REB/AST) calibration report with quantile coverage, bias, interval sharpness, Brier score, ECE, and auto-diagnosis.

## Context

Backtesting showed stats perform very differently (REB +7.9% ROI, AST marginal/negative), but the model treats all stats identically during calibration. C2 was the next step on Track C (Calibration Refinement) to provide per-stat visibility before deciding on per-stat fixes.

## Changes Made

### 1. New File: `src/diagnostics/calibration_per_stat.py`

~620 lines. Standalone diagnostic script with:

**Data Loading:**
- `load_from_csv()` — reads backtest `predictions.csv` files
- `load_from_db()` — joins `daily_predictions` + `player_game_stats` tables
- `_normalize()` — ensures required columns, filters to requested stats

**Metric Functions (all compute per-stat + global):**
- `compute_quantile_coverage()` — P(actual <= pred_q) for Q10–Q90, gap analysis, worst quantile
- `compute_bias()` — mean predicted vs mean actual, relative bias %
- `compute_sharpness()` — 80% and 50% interval widths
- `compute_brier_score()` — mean((over_prob - hit)^2)
- `compute_ece()` — Expected Calibration Error with 10-bin reliability curve

**Diagnosis Engine:**
- `generate_diagnoses()` — flags stats exceeding tolerances for coverage gap (configurable), bias (>5%), ECE (>0.05)

**Output:**
- `format_report()` — formatted console table output with ⚠ flags
- `build_json_report()` — structured JSON for programmatic use
- Windows-safe Unicode handling via `io.TextIOWrapper` for cp1252 terminals

**CLI:**
- `--csv` / `--db` (mutually exclusive, required)
- `--start` / `--end` (for DB mode)
- `--output` (JSON export)
- `--tolerance` (default 0.03)
- `--stats` (default: pts reb ast)
