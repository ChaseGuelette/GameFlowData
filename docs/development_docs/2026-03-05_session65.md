# Development Session 65 — 2026-03-05

## Summary

Bug fixes, edge refresh hardening, model promotion. Fixed dashboard showing no data for past dates, fixed edge refresh nulling old lines and timing out during game hours, removed failing NCAAB cron jobs, promoted retrained model to production, and investigated model under-bias (90% unders).

## Problems Addressed

### 1. Dashboard Empty on Past Dates
**Root cause:** `isGameDone(p.game_time)` filter in `dashboard/page.tsx` was applied to ALL dates. Since every game from a past date has ended, the filter removed ALL predictions. Users saw a blank page when selecting any date other than today.

**Fix:** Wrapped the `isGameDone()` and `showLive` filters in `selectedDate === getToday()` check so past dates show all predictions unconditionally.

### 2. Edge Refresh Nulling Old Lines
**Root cause:** `edge_refresh_job.py` performs a LEFT merge of stored predictions with fresh lines from `raw_player_props_combined`. When fresh lines aren't available (props pulled from the API, game started, etc.), the LEFT merge writes NULL into line/odds/bookmaker columns, destroying previously valid data.

**Fix:** Before the merge, save copies of the line columns. After the merge, use `fillna()` to restore old values where the merge produced NULLs.

### 3. Edge Refresh 45-Minute Timeouts
**Root cause:** The paper trading step runs `PaperTrader.select_bets()` which loads MC samples and runs Black-Litterman blending for every prediction. During game hours with many active predictions, this was causing 45-minute hangs that triggered Railway timeout alerts.

**Fix:** Added `--skip-paper` CLI flag to `edge_refresh_job.py`. Updated `scheduler.py`'s `run_edge_refresh_silent()` to pass `--skip-paper` for the 5-minute cron runs. Paper trading still runs during full inference jobs.

### 4. NCAAB Cron Jobs Failing on Railway
**Root cause:** Session 63 added 3 NCAAB cron jobs but migrations 009-011 aren't applied to Supabase, no historical data has been backfilled, and `cbbpy` isn't in `requirements.txt` on Railway.

**Fix:** Removed all 3 NCAAB job registrations, wrapper functions, and JOB_NAMES entries from `scheduler.py`.

### 5. Model Under-Bias (90% Unders)
**Investigation:** ~90% of recommended picks are unders. Analyzed the full pipeline: tail adjustment (negligible ~0.03 shift), conformal calibration (disabled in production per Session 42), per-quantile feature selection.

**Root cause:** PTS rate model at Q50 only uses 7 features — missing opponent defense, pace, and teammate injury context. The feature selector prunes matchup features because they don't improve pinball loss enough. REB model uses 27 features including these.

**Recommendation:** Selective PTS retrain with force-included matchup features (action item #22).
