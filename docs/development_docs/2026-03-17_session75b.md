# Development Session 75b -- 2026-03-17

## Summary

Diagnosed and fixed a 4:15 PM inference job timeout on Railway, recovered inference with the new production model, and tightened calibration monitoring thresholds for earlier drift detection.

## What Was Done

### 1. Diagnosed 4:15 PM Inference Timeout

**Symptom:** User reported "2pm inference job failed." Railway logs confirmed the 4:15 PM UTC run started at 16:15:00 and timed out at exactly 17:00:00 (45-minute Railway timeout). The 12:15 PM run succeeded in ~2.5 min.

**Root cause:** `PaperTrader.select_bets()` hangs during game hours when loading MC samples and computing Black-Litterman blending. This is the same issue fixed in Session 65 for `edge_refresh_job.py` with `--skip-paper`.

**Fix:** Added `skip_bets: bool = False` parameter to `run_inference()` in `scheduler.py`. The 4:15 PM cron job now uses `lambda: run_inference(skip_bets=True)`, which passes `--skip-bets` to `inference_job.py`. Paper bets are already placed at noon, so the 4 PM run only needs to refresh predictions.

### 2. Fixed TBD Game Times

**Symptom:** All 603 predictions had `game_time = NULL`, showing "TBD" on the dashboard.

**Root cause:** `raw_game_lines_staging` was completely empty — `lines_job.py` hadn't run (either on Railway or locally). The `_enrich_game_times()` function in `daily_runner.py` reads game times from this staging table.

**Fix:** Manually ran `daily_game_lines_scraper.py --date 2026-03-17` (1066 rows inserted, 534 in staging for today), then re-ran inference which enriched all 10 games with start times.

**Note:** `lines_job.py` fails on Windows due to `shlex.split()` treating backslashes as escape characters (`[WinError 2]`). Ran the scraper directly as a workaround.

## Key Findings

### Paper Trading Hang During Game Hours

This is a recurring issue: any code path that loads MC samples (10K per prediction) and runs BL blending can hang when invoked during active game hours. Two jobs now skip paper trading during their runs:
- `edge_refresh_job.py` — uses `--skip-paper` (Session 65 fix)
- `inference_job.py` at 4:15 PM — uses `--skip-bets` (this session)

The noon inference run handles all bet placement since games haven't started yet.

### lines_job.py Windows Incompatibility

`shlex.split()` treats Windows backslashes in `sys.executable` paths as escape characters, causing `[WinError 2]`. Not blocking (Railway runs Linux), but prevents local testing of the job wrapper. Direct scraper invocation works fine.
