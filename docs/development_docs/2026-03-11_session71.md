## Key Design Decisions

- **Edge ties → Under:** When `overEdge === underEdge`, classified as Under. Matches PropCard behavior.
- **NaN edges → 0:** `Number.isFinite()` guard defaults non-finite edges to 0. Matches PropCard.
- **Independent direction filters per tab:** My Bets and Model History have separate direction filter state, same pattern as status filters.
- **Direction filter before status filter:** Summary cards reflect direction filter even when status filter is applied.
- **CDN-only on Railway:** Advanced stats scraping NEVER runs on Railway. Railway daily_stats_job always uses `--cdn-only`. Advanced stats run locally via Windows Task Scheduler at 9 AM.
