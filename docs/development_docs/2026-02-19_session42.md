# Development Session 42 — 2026-02-19

## Summary

Implemented combined conformal recalibration for the Monte Carlo predictor to address the AST Q10 calibration gap (+10.25%). Built the full mechanism (offset computation, sample warping, `--calibrate-only` CLI mode), then validated via A/B backtest. Results showed offsets hurt betting performance — decided to archive the investigation and keep code dormant.

## Problem

The AST combined distribution has a persistent Q10 over-coverage of +10.25% (actual 20.25% when target is 10%). Previous sessions (40-41) attempted surgical retrains which showed diminishing returns and introduced Q50 regressions. The root cause is structural: ~18% of player-games have 0 assists, setting an irreducible floor on Q10 coverage.

## Approach: Combined Conformal Recalibration

Applied the same conformal recalibration pattern used for individual models, but on the **combined** (minutes x rate) distribution:

1. For each calibration game, collect `(actual_stat, predicted_quantile_value)` pairs
2. Compute `residuals = actuals - predicted_q_values`
3. For each stat and quantile: `offset = np.quantile(residuals, q)`
4. At inference, warp MC samples through piecewise-linear quantile corrections using `np.interp`

### Key Design Decisions

- **Sample warping, not quantile adjustment** — `prob_over(line)` uses `(samples > line).mean()`, so actual samples must be adjusted
- **Piecewise-linear interpolation** — Warps samples smoothly between calibrated quantile anchor points; preserves distribution shape
- **Backward compatible** — When `combined_calibration_offsets.json` is absent, `None` is returned and no warping occurs

## A/B Backtest Results

Ran backtests on Jan 15 – Feb 14, 2026 (after recomputing offsets with `--cal-end-date 2026-01-15` to avoid data leakage):

| Metric | Without Offsets | With Offsets |
|--------|----------------|--------------|
| Total Bets | 409 | 410 |
| ROI | **7.44%** | 6.01% |
| Sharpe | **0.891** | 0.742 |
| Hit Rate | 60.4% | 58.5% |
| Max Drawdown | 26.5% | 27.9% |
| PTS ROI | **13.7%** | 9.0% |
| REB ROI | 0.4% | 2.7% |
| AST ROI | 7.0% | 6.4% |

**Conclusion:** Offsets improved calibration metrics but degraded betting ROI by 1.43 percentage points. PTS (already well-calibrated) was most harmed — its Q50 offset of +0.83 shifted predictions away from profitable territory.

## Root Cause Analysis

The AST Q10 gap is structural, not a model deficiency:
- ~18% of player-games have 0 assists → Q10 is already at the floor
- Conformal offset for AST Q10 was -0.001 (essentially zero — can't push below 0)
- PTS/REB models were already well-calibrated; applying offsets to them was counterproductive
- Better calibration metrics =/= better betting performance

## Decision

**Archived the calibration investigation (Sessions 40-42).** The code remains in place as infrastructure for future use, but:
- `combined_calibration_offsets.json` is **not** in the production model directory
- No offsets are applied during inference or backtesting
- The `--calibrate-only` CLI mode is available if revisited

## Key Learning

Calibration improvement does not imply betting performance improvement. The relationship between statistical calibration and profitability is non-linear — well-calibrated predictions in unprofitable regions can dilute edge concentration. Empirical A/B backtesting is the only reliable way to validate changes that affect the betting pipeline.
