# Development Session 35 — 2026-02-18

## Summary

Pivoted from paid subscription model to free Discord funnel. Removed paywall, opened RLS to all authenticated users, added public picks page for social sharing, and replaced all paid messaging with free-beta + Discord CTAs.

## Context

Sessions 29-34 built subscription infrastructure (RLS, middleware paywall, pricing pages, route groups). Strategy shifted: instead of charging $19.99/mo immediately, build credibility first by posting free picks on socials/Discord, collecting emails via free signup, and flipping Stripe on later (~200 Discord members).

## Changes Made

### 1. Database — Open RLS (Migration: `remove_subscriber_only_rls_policies`)

Dropped subscriber-only RLS policies on 4 tables:
- `daily_predictions`
- `daily_prediction_samples`
- `paper_bets`
- `paper_trading_daily_log`

Replaced with `authenticated USING (true)` — any logged-in user can read.

### 2. Database — Public Picks RPC (Migration: `create_public_picks_rpc`)

Created `get_public_picks(pick_limit)` function:
- Returns top N recommended picks for current date
- Ordered by highest BL edge
- `SECURITY DEFINER` — bypasses RLS for anon access
- Granted to both `anon` and `authenticated` roles

### 3. Shared Constants

Created `dashboard/src/lib/constants.ts`:
- `DISCORD_URL = 'https://discord.gg/gameflow'` (placeholder)
- `TEAM_ABBREV` map extracted from dashboard page

### 4. Middleware — Remove Subscription Gate

Modified `dashboard/src/lib/supabase/middleware.ts`:
- Added `/picks` to `PUBLIC_ROUTES`
- Deleted `SUBSCRIPTION_EXEMPT_ROUTES`
- Deleted entire subscription check block (DB query + redirect to `/subscribe`)
- Result: auth-only gate on protected routes, no paywall

### 5. Public Picks Page

Created `dashboard/src/app/(public)/picks/page.tsx`:
