**Goal:** Get notified when any scheduled job (daily_stats, lines, inference) completes on Railway.

**Implementation:**

```python
    job_name: str,

    duration_seconds: float,
    metrics: dict | None = None,
    error_message: str | None = None,
    channel_id: str | None = None,
) -> bool:
    """Send job status alert to Discord #alerts channel."""
```

Modified `src/orchestration/scheduler.py` to track job duration and send alerts:

```python
JOB_NAMES = {
    "daily_stats_job.py": "Daily Stats",
    "lines_job.py": "Lines Scraper",
    "inference_job.py": "Inference",
}

def _send_job_alert(script_name, success, duration, stdout, stderr):
    """Send Discord alert for job completion. Non-fatal."""
    from src.discord_bot.alerts import send_job_alert_sync

    job_name = JOB_NAMES.get(script_name, script_name)
    metrics = _parse_metrics_from_output(script_name, stdout, stderr)
    error_msg = stderr[:500] if not success and stderr else None

    send_job_alert_sync(job_name, success, duration, metrics, error_msg)
```

**Alert Features:**
- Success: Shows job name, duration, and extracted metrics (when available)
- Failure: Shows job name, duration, and error details
- Non-fatal: Alert failures are logged but don't affect job execution
- Color-coded embeds: Green for success, red for failure

```python
) -> bool:

```

Modified `src/orchestration/daily_stats_job.py` to send summary after bet resolution:

```python
def _send_pnl_summary(result: dict) -> None:
    """Send daily P&L summary to Discord performance channel."""
    from src.discord_bot.alerts import send_pnl_summary_sync
    from src.discord_bot.services.paper_trading import get_bankroll_summary

    bankroll_data = asyncio.run(get_bankroll_summary())
    if bankroll_data:
        send_pnl_summary_sync(
            resolution_result=result,
            bankroll=bankroll_data.get("balance", 1000.0),
            daily_pnl=bankroll_data.get("daily_pnl", 0.0),
            total_pnl=bankroll_data.get("total_pnl", 0.0),
        )
```

**Summary Features:**
- Win/Loss/Push record from bet resolution
- Daily P&L (gain/loss for the day)
- Cumulative P&L (total since inception)
- Current bankroll
- Color-coded embeds: Green for profit, red for loss
