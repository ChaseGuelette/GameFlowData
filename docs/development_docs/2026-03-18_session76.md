### 3. Backfill Script

**File:** `src/processing/backfill_starter_data.py` (NEW)

- Queries distinct `game_id` values from `player_game_stats` where `started IS NULL`
- Fetches CDN boxscore JSON per game, extracts `starter` field per player
- Rate-limited at 0.5s/game, logs progress every 100 games
- CDN only keeps ~2 recent seasons of boxscores; older games return 404
- Fallback: `UPDATE SET started = (min >= 20) WHERE started IS NULL`
- CLI: `--season`, `--dry-run`

**Backfill results:**
- ~12,000 older games: CDN 404 (expected — data not available for older seasons)
- ~2,889+ recent games (2024-25 and 2025-26): CDN success with real starter data
- Remaining games: filled with `min >= 20` proxy fallback

## Key Findings

### CDN Boxscore Data Availability
The NBA CDN only keeps boxscore JSON for approximately the last 2 seasons. Games from 2022-23 and earlier return 404. This means real starter data is only available for recent games; older games rely on the `min >= 20` proxy. This is acceptable since the proxy is reasonably accurate for historical data and training primarily uses recent seasons.

### Season ID Format Gotcha
The `populate_average_stats.py --season` flag uses the database season ID format (`22024`) not the human-readable format (`2024-25`). Using the wrong format silently returns 0 rows.
