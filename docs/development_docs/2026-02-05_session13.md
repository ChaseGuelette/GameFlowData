## Work Completed

### 1. Daily Stats Job

**Location:** `src/orchestration/daily_stats_job.py`

**Purpose:** Once-daily (6 AM ET) scraping of NBA game results from the previous night, followed by the full processing pipeline to update derived stats.

**Steps:**
1. `nba_unified_scraper.py` — Fetch latest game box scores
2. `nba_linker_local.py incremental` — Link unmatched props
3. `backfill_team_ids.py` — Fill missing team IDs
4. `update_player_position_history.py` — Update position snapshots
5. `update_league_position_averages.py` — Update league averages
6. `populate_average_stats.py` — Compute rolling averages (L3, L5, L15)
7. `backfill_opponent_allowed.py` — Update opponent-adjusted stats

**Runtime:** ~2-5 minutes

### 2. Lines Job

**Location:** `src/orchestration/lines_job.py`

**Purpose:** Multiple-times-daily (12 PM, 4 PM, 6 PM ET) scraping of player props and injuries to capture line movement.

**Steps:**
1. `daily_game_lines_scraper.py` — Fetch game lines (spreads, totals)
2. `daily_player_props_scraper.py` — Fetch player props
3. `rapidapi_injury_backfill.py` — Fetch injury updates (optional)
4. `link_injury_data.py` — Link injury player IDs (optional)
5. `nba_linker_local.py incremental` — Link new props (optional)

**CLI Options:**
- `--date YYYY-MM-DD` — Target date
- `--skip-injuries` — Faster execution, skip injury scraping
- `--skip-linker` — Skip incremental linker if already run
- `--dry-run` — Preview commands without executing

**Runtime:** ~30-90 seconds

### 3. Inference Job

**Location:** `src/orchestration/inference_job.py`

**Purpose:** Pre-game (6:30 PM ET) prediction generation using the latest model artifacts and prop lines.

**Steps:**
1. Load model artifacts (auto-detects latest `run_*` directory)
2. Initialize FeatureStore and MonteCarloPredictor (10,000 samples)
3. Load Gaussian copula params for correlated sampling
4. Run `DailyPredictionRunner.run_for_date()`
5. Store predictions to `daily_predictions` table
6. Store MC samples to `daily_prediction_samples` table
7. Export CSV backup to `predictions/predictions_YYYY-MM-DD.csv`

**CLI Options:**
- `--date YYYY-MM-DD` — Target date
- `--model-dir PATH` — Specific model artifacts path
- `--stats STAT [STAT ...]` — Stats to predict (default: pts reb ast)
- `--dry-run` — Generate predictions but don't store to DB

**Runtime:** ~1-3 minutes

## Root Cause Analysis

**Missing backtest bets after Jan 9:** Investigated why the backtest showed hundreds of bets from Jan 1-9 but zero after. Root cause: the `game_id_map_staging` table lacks mappings for games after Jan 10 because the linker upload step never completed.

- The `props_game_updates.csv` file has mappings through Jan 23
- But the upload to database was never run
- **Fix:** `python src/processing/nba_linker_local.py upload`
