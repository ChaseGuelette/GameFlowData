# Development Session 52 — 2026-02-28

## Summary

Added live betting toggle to the main predictions dashboard and PrizePicks 2-Pick slip type to the DFS Edge Finder. Both are frontend-only changes — no backend or database modifications needed.

## What Was Built

### 1. Live Betting Toggle (`dashboard/page.tsx`)

Pill-style "Pre-Game / + Live" toggle added to the dashboard header controls (next to Model Picks toggle).

**Behavior:**
- **Pre-Game (default):** Hides predictions whose `game_time` has passed (game started or finished). Prevents users from seeing stale predictions for in-progress games.
- **+ Live (orange pill):** Shows all predictions including live games.

**Implementation:**
- New state: `const [showLive, setShowLive] = useState<boolean>(false)`
- Filter in `filteredPredictions`: `if (!showLive && p.game_time) { if (new Date(p.game_time) <= new Date()) return false }`
- Client-side time comparison — no backend changes needed since `game_time` is already available on each prediction.
- Uses same pill-toggle styling pattern as the existing Model Picks toggle (slate-700 for default, orange-600 for active Live state).

### 2. DFS PP 2-Pick Slip Type (`dfs.ts`)

Added PrizePicks 2-Pick Power to the `DFS_SLIP_TYPES` constant:

```typescript
'pp_2_power': { label: 'PP 2-Pick', breakEven: 0.577, payout: '3x' }
```

- **Break-even per leg:** 57.7% (`1/√3 ≈ 0.577`)
- **Payout:** 3x
- This is the most conservative slip type — highest per-leg threshold — meaning only genuinely mispriced lines will show positive edge.
- Automatically appears in the DFS Edge Finder dropdown alongside existing options.

## Technical Decisions

1. **Client-side time comparison** — The `game_time` field is already a UTC timestamp from the NBA API stored on each prediction. Comparing against `new Date()` is sufficient and avoids any backend changes.

2. **Default to Pre-Game** — Users primarily want pre-game predictions. Live game predictions are based on pre-game models and may not accurately reflect in-game dynamics. The toggle lets power users opt in to seeing them.

3. **57.7% break-even for 2-pick** — Derived from `1/√3` where 3x is the payout. This means for a 2-pick 3x payout, each leg needs `√(1/3) = 57.7%` probability to break even.
