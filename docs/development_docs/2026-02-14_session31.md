## Key Accomplishments

### 1. Vercel Deployment Fix

**Root Cause:** `dashboard/package.json` and `dashboard/tsconfig.json` were never committed to git because of `*.json` in `.gitignore`.

**Symptoms:**
- All routes returning 404
- Builds completing in 18ms (should be 30-60+ seconds)
- `"framework": null` — Vercel didn't detect Next.js
- "Module not found: Can't resolve '@/components/...'" errors

**Investigation Steps:**
1. Used Vercel MCP tools to check deployment status
2. Found `state: "READY"` but suspiciously fast builds
3. Checked build logs — "No files were prepared"
4. Checked runtime logs — all 404 responses
5. Discovered missing config files via git status

**Fix Applied:**

`.gitignore` additions:
```gitignore
*.json
!package.json
!package-lock.json
!vercel.json
!tsconfig.json
```

`dashboard/tsconfig.json` fix:
```json
{
  "compilerOptions": {
    "baseUrl": ".",  // Required for @/* path alias
    "paths": {
      "@/*": ["./src/*"]
    }
    // ...
  }
}
```

**Vercel Settings:**
- User disabled "Include files outside the root directory" (was causing path confusion)

**Result:**
- Dashboard live at `game-flow-data.vercel.app`
- Routes now returning 200 status
- `/` redirects to `/login` (expected auth behavior)

### 2. Model Picks Filtering

**Problem:** History and Performance pages showed all bets, but users wanted to see Model Picks performance separately — the actual profit from following the model's best recommendations.

**Solution:** Added `BetSourceFilter` component with toggle between "Model Picks" (edge ≥9%) and "All Bets".

**New Component:**

`dashboard/src/components/shared/BetSourceFilter.tsx`:
```tsx
export type BetSource = 'model' | 'all'

export const MODEL_PICKS_EDGE_THRESHOLD = 0.09  // 9% edge

export function BetSourceFilter({ activeSource, onSourceChange, className }) {
  return (
    <div className={cn('flex items-center gap-2', className)}>
      {SOURCES.map((source) => (
        <button
          key={source.value}
          onClick={() => onSourceChange(source.value)}
          className={cn(
            'px-4 py-2 rounded-lg text-sm font-medium transition-colors',
            activeSource === source.value
              ? 'bg-emerald-600 text-white'
              : 'bg-slate-700 text-slate-300 hover:bg-slate-600'
          )}
        >
          {source.label}
        </button>
      ))}
    </div>
  )
}
```

## Design Decisions

### Default to Model Picks

**Chosen:** `betSource` defaults to `'model'`

**Rationale:**
- Users care most about model performance
- Shows what happens when following model recommendations
- All Bets includes lower-confidence picks that dilute results

### Simulate Model-Picks Bankroll

**Chosen:** Recalculate bankroll progression from filtered bets

**Rationale:**
- Daily log (`paper_trading_daily_log`) aggregates ALL bets
- When filtering to Model Picks, need to simulate what bankroll WOULD be
- Start at initial $1000, add daily P&L from model picks only

### 9% Edge Threshold

**Chosen:** Use `MODEL_PICKS_EDGE_THRESHOLD = 0.09`

**Rationale:**
- Matches production model configuration
- Derived from backtest optimization
- Consistent with "Model Picks" toggle on home page
