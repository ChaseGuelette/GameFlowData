### 1. Incomplete Model Directory Fix

**Problem:** Backtest sweeps were returning 0 bets across all configurations. The sweep showed `game_dates: 0` and `total_predictions: 0`.

**Root Cause:** `find_latest_model_dir()` in `run_sweep.py` was auto-selecting `run_20260206_171812`, an incomplete training run that only contained `run_config.json` (no model files). The training was started but never completed.

**Fix:** Updated `find_latest_model_dir()` to validate that `minutes_model.joblib` exists before selecting a directory:

```python
def find_latest_model_dir(base_dir: str) -> Path:
    """Find the most recent COMPLETE run_* directory in the artifacts folder."""
    # ... existing logic ...

    # Find first complete run (has minutes_model.joblib)
    for run_dir in runs:
        if (run_dir / "minutes_model.joblib").exists():
            return run_dir
        logger.warning(f"Skipping incomplete model directory: {run_dir.name}")

    raise FileNotFoundError(
        f"No complete model artifacts found in {base}. "
        f"Checked {len(runs)} directories but none contained minutes_model.joblib."
    )
```

**Location:** `src/backtesting/run_sweep.py` lines 560-592

### 2. Game ID Format Mismatch Fix

**Problem:** Even after fixing the model directory issue, the backtest was only finding 397 lines for Jan 16-29 vs 33,565 for Jan 1-15.

**Root Cause:** Game ID format mismatch between tables:
- `player_game_stats.game_id`: 10-digit format with leading zeros (e.g., `0022500589`)
- `raw_player_props_combined.game_id`: 8-digit format without leading zeros (e.g., `22500589`)

The JOIN in the prefetch lines query failed because `'0022500589' != '22500589'`.

**Fix (Query):** Updated the backtest harness query to use `LPAD` for compatibility:

```sql
-- Before
JOIN game_dates gd ON rp.game_id = gd.game_id

-- After
JOIN game_dates gd ON LPAD(rp.game_id, 10, '0') = gd.game_id
```

**Location:** `src/backtesting/backtest_harness.py` line 556

**Fix (Linker):** Added `.zfill(10)` when storing game_ids in lookup dictionaries to ensure future linker runs produce correctly formatted IDs:

```python
# Ensure game_id is a 10-digit string with leading zeros
game_id = str(row["game_id"]).zfill(10) if pd.notna(row["game_id"]) else None
```

**Locations:** `src/processing/nba_linker_local.py` lines 355-357, 374-377, 916-919

## Key Learnings

1. **Silent failures are dangerous:** The incomplete model directory caused the entire backtest to fail silently (0 predictions), returning all-zero metrics that looked like valid results.

2. **Data format consistency matters:** The game_id format mismatch was subtle — both formats were valid game IDs, but the JOIN failed because of leading zeros. Always validate format consistency across related tables.

3. **Investigation approach:** The systematic approach of checking each stage (model loading → prediction → line fetching → betting) helped isolate the root causes quickly.
