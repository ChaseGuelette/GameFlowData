## Technical Design Decisions

### 1. Async Database Queries

```python
async def get_predictions() -> list[dict]:
    def _query():
        engine = get_engine()
        with engine.connect() as conn:
            result = conn.execute(text(query))
            return [dict(zip(columns, row)) for row in rows]
    return await asyncio.to_thread(_query)
```

Used `asyncio.to_thread()` to wrap synchronous SQLAlchemy queries for Discord.py's async event loop.

### 2. Slash Commands vs REST API

- **Slash commands** require bot process running continuously
- **Alerts** use REST API directly — no bot process needed
- This separation allows alerts to work even if bot is down

### 3. Simplified Architecture

Original plan had separate files per command, but implemented with:
- All commands inline in `bot.py` (simpler, less boilerplate)
- Two service files (`predictions.py`, `paper_trading.py`)
- One formatter file (`embeds.py`)

## Bugs Fixed During Implementation

### 1. Teams Table Column Error
```
column t.abbreviation does not exist
```
**Fix:** Changed `t.abbreviation` to `t.team_name` — the `teams` table only has `team_id` and `team_name`. Used `dp.feat_opp_abbrev` from predictions table for opponent.

### 2. Paper Bets Column Errors
```
column "result" does not exist
column "stat" does not exist
```
**Fix:** Updated column names to match actual schema:
- `result` → `status`, with values `'won'`/`'lost'` instead of `'win'`/`'loss'`
- `stat` → `stat_type`
- `side` → `bet_direction`
- `odds` → `odds_at_bet`

### 3. Paper Trading Daily Log Column Error
```
column "current_bankroll" does not exist
```
**Fix:** Changed to actual column names:
- `current_bankroll` → `bankroll_after`
- Used `total_pnl` for daily P&L
- Used `cumulative_pnl` for total P&L
