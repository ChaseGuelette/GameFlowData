### 1. BL Confidence Function Fix (A3b)

**Problem:** The exponential confidence formula `1 - exp(-0.5 * z²)` produced near-zero confidence for realistic betting edges. At z=0.13 (typical 3% edge), confidence was only 0.008, making the effective weight ~0.0008 and crushing all edges below practical thresholds.

**Solution:** Replaced with linear ramp formula: `confidence = min(z / z_max, 1.0)`

**Implementation:**
- Added `z_max: float = 1.0` parameter to `BLConfig` dataclass
- Changed `compute_confidence()` in `src/models/black_litterman.py`
- Updated docstring to describe linear ramp behavior

**Impact:** At z=0.13, confidence is now 0.13 instead of 0.008 — a 16x improvement in effective weight. BL should now produce meaningful bet counts and sizing.

### 3. THREES Hurdle Model Implementation (C3)

**Problem:** THREES Q0.10 had +20.4% calibration gap (coverage 35.2% vs target 10%). Root cause: ~35% of `threes_per_min` samples are exactly 0, but XGBoost's `quantileerror` objective always predicts positive values — it cannot learn Q0.10 = 0.

**Solution:** Two-stage hurdle model architecture:

**Stage 1 — Zero Classifier:**
- XGBoost binary classifier predicting P(threes = 0 | features)
- Isotonic regression calibration for accurate p_zero estimates
- Features: Same as rate model (position/role features likely prioritized)

**Stage 2 — Positive Quantile Models:**
- Standard XGBoost quantile regression
- Training data: Filtered to non-zero samples only (threes | threes > 0)
- Per-quantile models with conformal recalibration

**Combined Inference:**
- For target quantile q: if q ≤ p_zero → return 0
- Otherwise: `adjusted_q = (q - p_zero) / (1 - p_zero)`, then interpolate positive distribution

**MC Sampling:**
- Bernoulli draw (independent of copula) determines zero vs positive
- For positive samples: copula-correlated uniforms map through positive distribution inverse CDF
- Key insight: Copula affects positive rate magnitude, not zero/positive decision

## Design Decisions

1. **Isotonic calibration for classifier:** Raw XGBoost classifier probabilities can be miscalibrated. Applied isotonic regression on validation set to ensure accurate p_zero estimates, which directly affect quantile mapping.

2. **Independent Bernoulli draw:** The zero/positive decision is independent of the copula. A player who plays more minutes isn't necessarily more/less likely to score zero 3s (that's role-driven). Copula only affects the positive rate magnitude.

3. **Interpolation for adjusted quantiles:** When predicting quantile q > p_zero, we compute `adjusted_q = (q - p_zero) / (1 - p_zero)` and interpolate between trained positive quantiles. This maps the full [0, 1] quantile range onto the positive distribution.

4. **Automatic detection:** The pipeline automatically uses hurdle model for THREES when training. The MC predictor automatically detects hurdle models via `threes_is_hurdle.json` flag file.
