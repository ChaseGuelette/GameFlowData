Definitions and defaults

Pitcher historical IP context, strictly previous appearances/starts as noted:
- `pitcher_max_ip_l5`: max `ip` over previous 5 pitcher appearances for same player/season. Default: `pitcher_avg_ip_l5` or 0.
- `pitcher_median_ip_l5`: median `ip` over previous 5 pitcher appearances for same player/season. In Postgres use `percentile_cont(0.5) WITHIN GROUP (ORDER BY ip)` over the limited history subquery. Default: `pitcher_avg_ip_l5` or 0.
- `pitcher_ip_range_l5`: `max_ip_l5 - min_ip_l5`, clipped/COALESCE to 0 if null.
- `pitcher_short_start_rate_l5`: fraction of previous 5 starts/appearances with `ip < 4.0`. Default 0.
- `pitcher_start_stability_l5`: `starts_l5 / 5.0`, default 0.

Batters faced approximations from existing columns:
- No official BF column exists. Use approximation: `outs_recorded + h_allowed + bb` for per-game history.
- `pitcher_avg_batters_faced_l5`: for model rows, prefer `(avg_ip_l5 * 3) + avg_h_allowed_l5 + avg_bb_l5`; for more exact LATERAL history, use average of `(outs_recorded + h_allowed + bb)` over previous 5. Either is acceptable, but be consistent across training and inference.
- `pitcher_avg_batters_faced_szn`: `(avg_ip_szn * 3) + avg_h_allowed_szn + avg_bb_szn`.

Pitch count/workload:
- `pitcher_avg_pitches_per_start_l5`: use `avg_pitches_thrown_l5` for now. Naming is start-oriented but source rolling is appearances; only starters are training rows, so this is acceptable.
- `pitcher_workload_spike_ratio`: `pitch_count_last_start / NULLIF(avg_pitches_thrown_l5, 0)`, default 1.0.
- `pitcher_recent_pitch_count_trend`: `avg_pitches_thrown_l3 / NULLIF(avg_pitches_thrown_l5, 0)`, default 1.0.
- `rest_after_high_pitch_count`: `(days_rest / 5.0) * (pitch_count_last_start / 100.0)`, default 0.

Team/starter leash:
- `team_starter_avg_ip_l10`: average starter `ip` for the pitcher’s own team over previous 10 starter games before target date. Filter `is_starter = TRUE`, `did_not_play = FALSE`, `team_id = current pitcher team_id`, `game_date < target_game_date`.
- `team_starter_short_start_rate_l10`: fraction of those previous 10 team starter games with `ip < 4.0`.
- `team_starter_avg_pitches_l10`: average `pitches_thrown` over those previous 10 team starter games.

Bullpen pressure:
- `bullpen_fatigue_pressure`: combine existing own-team bullpen features: `(team_bullpen_ip_last_3d / 9.0) + (team_bullpen_pitches_last_3d / 150.0)`, default 0. Use fields already joined as `bull.bullpen_ip_last_3d`, `bull.bullpen_pitches_last_3d`.

Opponent contact features:
- Update `src/processing/mlb/mlb_matchup_features.py` in both single-game and bulk functions.
- `opp_team_contact_rate_l10`: `1.0 - opp_team_whiff_pct_l10` when whiff exists; default null/None so feature store fillna handles it.
- `opp_team_chase_pct_l10`: team rolling L10 average of raw `mlb_player_game_statcast_batting.chase_pct`, weighted by `total_pitches_seen` when present.
- `opp_team_zone_contact_pct_l10`: no true zone-contact source exists; implement a documented proxy using team game statcast: `zone_pct * (1.0 - whiff_pct)` weighted by `total_pitches_seen`. Name stays as requested; add comment that it is a proxy until true zone-contact exists.
