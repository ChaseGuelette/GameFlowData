Behavior-preservation decisions

  • Feature constants were moved into src/models/mlb/features/contracts.py and re-exported through the legacy facade modules so existing imports remain stable.
  • Pure transform helpers preserve the legacy in-place mutation behavior. This includes temporary helper-column creation/removal in batter projected-AB logic and pitcher default-column creation.
  • The first prop-line extraction only centralizes the single-player _get_prop_line path. Training/date-batch lateral SQL still contains inline prop-line clauses and is deferred so we do not silently change promotion-critical query semantics.
  • Request/loader modules were introduced as compatibility shells around existing facade methods. Production callsites were not migrated directly in this slice.

Deferred safety boundaries

  • Full facade thinning to under 600 non-comment LOC remains deferred. Inventory tests currently document, but do not enforce, that destination.
  • Shared/pitcher/batter source modules currently establish tested boundaries and default/query policies; they do not yet own all source-specific SQL from the facades.
  • Promotion-grade enforcement for as_of_time=None remains in temporal_contracts.py as an explicit contract but has not been wired into all public callsites. Legacy behavior remains preserved.
  • No DB-heavy audits, model retrains, long backtests, or production daily-runner rewires were performed.
