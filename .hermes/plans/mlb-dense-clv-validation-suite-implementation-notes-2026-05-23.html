MLB Dense CLV Validation Suite Implementation Notes

Companion notes for the 2026-05-23 dense CLV validation-suite implementation. This records decisions/research/issues discovered during implementation that were not explicit in the architecture plan.

Decision: dense CLV sync must be bounded unless explicitly overridden

mlb_player_props_clv_snapshots is now registered as an incremental MLB sync table on snapshot_time. An unbounded --full refresh of this table is blocked unless the caller supplies --allow-large-full-refresh. Date windows should be preferred for local dense CLV prep.

Decision: slate_or_tminus missing decision metadata is WARN, not FAIL

The existing dropout audit was falsely applying the fixed 13:30 ET cutoff to all selected clean quotes, which is invalid for dynamic policies such as slate_or_tminus. The audit now checks fixed cutoffs only for fixed policies, uses row-level decision-time columns when available, always checks commence-time violations, and returns WARN if dynamic-policy decision metadata is missing.

Verified: current quote-clean artifacts carry selected_decision_time

Follow-up inspection found src/backtesting/mlb/quote_clean_line_service.py adds selected_decision_time and quote_decision_policy to line-selection output. Existing dense slate artifacts under backtest_results/mlb_batter_hits_dense_quote_clean_slate_tminus60_20260413_20260517 and backtest_results/mlb_batter_hits_dense_slate_t60_promoted_20260413_20260517 also have selected_decision_time in predictions.csv and bets.csv. The WARN path remains only as a defensive guard for older/stale artifacts.

Decision: suite_summary.md is now gate-oriented

The suite manifest/summary now includes a validation gate report with ROI/bets/profit, CLV CI lows, edge-ranking CI low, bookmaker concentration/ESPNBet fields, dropout decision, and per-config gate status. This makes the output usable for Go/No-Go review without hand-reading every child artifact.

Decision: duplicate only the CLI artifact contract into decomposed sweep tests

The dense CLV/audit scripts should remain script-level responsibilities: local DB sync windowing, dropout reporting, CLV gate aggregation, failure-mode diagnosis, and bookmaker sensitivity are not duplicated into run_mlb_sweep.py. The necessary sweep-side behavior is the artifact contract consumed by CLI sweeps/audits: selected quote bookmaker, selected/over/under snapshot timestamps, row-level selected_decision_time, and quote_decision_policy must survive line selection, fast base-prob precompute, per-config edge building, and CSV serialization.

Regression coverage was added in tests/test_mlb_sweep_edge_metadata_contract.py and tests/test_mlb_sweep_results.py. The focused CLI-facing suite passed: 50 passed, 1 warning.

Ready-to-run audit command shape

python scripts/run_mlb_quote_clean_audit_suite.py \
  --sweep-output-dir backtest_results/<existing_sweep_dir> \
  --output-dir backtest_results/<new_suite_dir> \
  --model-dir src/models/mlb/artifacts/production \
  --start 2026-04-13 \
  --end 2026-05-17 \
  --stats batter_hits \
  --quote-decision-policy slate_or_tminus \
  --quote-relative-minutes 60 \
  --line-source mlb_player_props_clv_snapshots \
  --snapshots-table mlb_player_props_clv_snapshots \
  --local
